# Bundled RETROBOY cartridges

These two Game Boy homebrew ROMs are included as redistributable open-source releases. The ROMs are stored as Base64 text files in this repository so GitHub's text-file interface can preserve their exact bytes; RETROBOY decodes them in the browser before passing them to EmulatorJS.
