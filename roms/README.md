# RETROBOY ROM collection

Place only ROM files that you created, are public domain, or are otherwise authorised for you to distribute with this site in this folder.

Then add an entry to `../games.json`, for example:

```json
{
  "games": [
    {
      "title": "My Homebrew Game",
      "system": "GAME BOY",
      "rom": "roms/my-homebrew-game.gb",
      "cover": "covers/my-homebrew-game.png",
      "art": "🕹️"
    }
  ]
}
```

Supported formats: `.gb`, `.gbc`, `.gba`, `.nds`, `.zip`, and `.7z`.
