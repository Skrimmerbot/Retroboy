# RETROBOY — Pocket-sized chaos 🎮

A funky retro arcade portal with a searchable game catalog and an in-browser Game Boy ROM launcher.

## Run it

This is a static site. Open `index.html` in a browser or deploy it with GitHub Pages.

## Enable GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the Pages workflow to finish. The site URL should be `https://skrimmerbot.github.io/Retroboy/`.

## Gameplay and ROMs

The launcher uses EmulatorJS via its public CDN. Select a `.gb` or `.gbc` ROM you are legally entitled to use; the file is loaded locally in your browser. RetroBoy does not bundle or host commercial ROMs.
